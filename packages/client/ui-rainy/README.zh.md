# Rainy 工作区界面

[English](README.md) | 中文

## 概述

该浏览器插件提供 RainyAgent 工作区编辑器、文件树、保留状态的 AI 对话、运行/调试面板及中央 CTF 工具工作台。编辑器状态按工作区保存，独立于对话。Host 在重启和浏览器 origin 变化后保留选中的工作区。Rainy 桌面 profile 默认包含该插件；卸载后恢复共享外壳及默认品牌外观。

## 使用本包

打开的文件夹成为项目主目录。“添加文件夹”把另一个独立目录加入项目，不改变会话工作目录。原生文件夹选择未完成时，目录操作入口暂时禁用；重叠请求共用第一次选择及其打开或附加动作，直到工作区接收目录。取消或失败后可以重新选择。文件标签、恢复缓冲区、断点和运行配置保留所属根目录，即使文件名相同也不会混淆。重复路径复用已有根目录，嵌套或重叠目录会被拒绝。移除附加文件夹不会删除文件，操作前必须保存或关闭其中已修改的缓冲区。

打开文件夹和选择“新建对话”不会创建 Session。首次提交文字或附件时，才在选中的项目创建会话。恢复项目时，仅当最近对话的工作目录匹配时才选中它，否则显示新草稿。从历史记录选中另一项目的对话时，会恢复该项目的编辑器，并保持所选对话。项目和会话恢复成功后文件树才可交互；恢复数据保存失败时保留当前项目及缓冲区。

设置在同一弹窗中提供模型、扩展、外观、运行环境和项目记忆页面。添加模型会清空此前的端点和密钥，本地上下文初始为 100,000 tokens，API 上下文初始为 1,000,000 tokens，输出上限自动分配。发现模型只需要连接字段，保存与诊断仍要求完整配置。profile 中的 `localModelContextWindow` 和 `apiModelContextWindow` 控制这些初始值；切换模型运行方式时，已保存或手动编辑的窗口值保持不变。记忆提供独立的读取与自动整理开关，以及当前项目条目的编辑和删除操作。运行环境选择检测已有解释器，不执行安装。组件准备过程显示进度或等待提示，并在原生流程完成或取消后刷新执行环境列表。菜单跟随弹窗的浅色或深色主题。设置不提供设备码、激活或续期入口。本包适用 [RainyAgent 源码可用许可](LICENSE)，上游组件保留各自许可。

Strata 卡片通过 `./strata-protocol` 中的桌面桥接管理内置引擎与 Python。使用者选择受支持的 Qwen3.8 Flash Next GGUF、模型目录或 Strata profile，并提供配套的 MTP GGUF 或已准备目录。MTP 路径留空表示自动检测，不表示关闭 MTP。选择或保存文件不会启动模型；明确启动后可在本机准备运行文件，并可取消。此集成不下载模型权重。已有外部服务可以连接，但不能由该卡片停止。

“连接并设为默认”先等待当前 Windows 或 WSL Host 验证已加载端点，再在既有模型表单中显示已保存的模型 ID 和实际上下文窗口。推理档位与每次请求的输出上限继续在该表单中管理。Host 无法访问 Strata 时显示连接错误，不会选择云端端点。刷新保留卡片中未保存的修改，也不会把旧轮询当作本次配置变更后的读取结果。

新工作区显示文件树和主编辑区；需要时通过顶栏展开 AI 和执行面板。已有工作区保留保存的面板开关与宽度。“视图 → 专注编辑”收起 AI 和底部面板，并保留其状态。文件栏只有一行操作；编辑器操作与文件标签共用一行，没有打开文件或工具标签时不显示该行。“文件”菜单提供 Windows 文件夹选择器及当前执行环境的目录浏览入口。快速打开搜索相对文件名，不读取源码内容，并提示结果截断。文件栏默认 240 px，AI 栏默认 400 px，两者均可调整宽度；空间不足时文件栏可在编辑器上方展开。模型、上下文、Skills、MCP、外观与偏好仍从统一设置入口访问；参见[桌面指南](../../../apps/rainy-desktop/README.zh.md)。

顶栏中部是项目切换器和“搜索文件”，后者显示快速打开的快捷键。编辑文件时右侧显示运行、调试及运行方式菜单（为当前文件改选语言或固定已保存配置），其后依次为文件栏、底部面板和 AI 面板开关、CTF 工具及设置。未打开项目时，编辑区提供“打开文件夹”（桌面文件夹选择器可用时）、“浏览当前执行环境文件夹”和最近项目；已打开项目但没有打开文件时，提供“搜索文件”“创建新文件”和“打开 AI 助手”。窗口底部的状态栏显示执行环境、保存状态、运行和调试活动、光标行列、选中长度、语言、行尾和编码。

Monaco 读取完整 UTF-8 源文件，切换标签时保留撤销历史、选区、光标与滚动位置。二进制、编码不受支持及过大文件显示元数据和有界的只读文本或十六进制预览；预览截断时明确标示，始终禁止保存局部文件。明确保存时比较最近观察到的磁盘版本；磁盘文件变化后保留本地缓冲区，并提供差异视图。确认冲突仅采用该差异已展示的版本。脏缓冲区在切换工作区和退出应用前单独保存为恢复数据；其他窗口的并发恢复写入会在仍有脏数据时阻止进一步恢复写入，源文件仍可明确保存。

已落定的 AI 回复代码可在只读临时编辑器标签中打开，未选择工作区时同样可用，也可与当前源码缓冲区比较。查看差异时保留未保存的源码修改；“应用到文件缓冲区”需明确点击，且不会保存文件。比较期间目标内容变化时，会刷新差异供再次检查。AI 临时预览不进入工作区文件的持久恢复数据。

Python、JavaScript、TypeScript、C、C++ 连接 Host 语言服务以提供诊断和导航。符号重命名会把此前未打开的修改文件保留为后台标签，纳入脏缓冲区恢复和明确的版本校验保存。格式化只修改编辑器缓冲区，不自动保存源文件。“运行”和“调试”先保存全部脏文件，再使用选中的工作区配置。命名配置保存程序/模块、参数、环境变量、解释器/编译器及单文件或 CMake 构建方式，包含可选的配置/构建预设。收起高级选项不会清除其值；配置弹窗在窗口内滚动，并保持保存按钮可见。切换编辑器标签时，交互终端、运行输出、断点、调用栈、变量和监视仍由各自工作区保留。C/C++ 调试控制台在选中的栈帧求值表达式，其他语言适配器接收 REPL 请求。调试只启动配置中的程序，不支持附加到其他进程。

Host 将经过校验的配置写入页面。`readyTimeoutMs` 与 `flushTimeoutMs` 控制工具 frame 的启动和持久保存确认；`editorPollMs` 观察已打开文件、空闲执行及可见模型设置（包括 Strata），`executionPollMs` 观察活动执行，`editorStateDebounceMs` 调度恢复写入；`editorMaxOutputCharacters`、`editorMaxRetainedWorkspaces`、`editorTerminalCols`、`editorTerminalRows` 限制保留的输出并初始化终端。配置变更在下次加载页面时生效。

顶栏“CTF 工具”按钮打开中央标签，无需先有对话。默认“常用工具”列表可搜索名称与本地化用途，按任务分组列出工具（Web 与接口、流量分析、逆向调试、取证与文件、隐写与图像、音频与信号、编码与数据），可按分组筛选，并查看收藏与最近打开记录。后续目录新增的工具按其签名分类归组。偏好属于桌面用户，在会话之间共享。桌面程序打开独立窗口，命令行工具打开准备好环境的终端，离线网页打开隔离工具窗口。缺少文件时禁止启动；可启动但未经实际验收的工具标记为“待验证”。启动提示仅确认系统已接受请求；界面是否就绪及功能是否通过验收需分别检查。x64dbg 条目同时提供 x32dbg 入口。

桌面 preload 提供 `./native-tools-protocol` 中固定 ID 的 `NativeToolsBridge`；客户端不发送路径或命令参数。启动失败保留目录，并通过外壳 toast 提示；收藏控件等待持久写入完成。系统已接受启动请求但最近使用记录写入失败时显示警告。缺少该桥接的浏览器仍提供 IceSky，并提示原生工具需要桌面应用。

工具文件缺失的卡片和目录读取失败提示提供“修复工具包”入口，点击后展开离线指引，不启动安装程序。请保存工作并退出 RainyAgent 及全部工具窗口，将匹配的安装 EXE 和全部工具包分卷放在同一目录，再次运行安装程序。安装完成后，重新打开 RainyAgent 并刷新工具状态。

IceSky 标签首次访问时加载一份 frame，隐藏后继续保留。切换会话会切换 frame 的逻辑草稿上下文，即使当前显示的是工具目录；未选中会话或处于空白“新会话”页面时使用独立上下文。模型和扩展入口打开桌面 profile 的认证设置弹窗，扩展默认选中当前会话。

CTF 跟随宿主解析后的语义 CSS 颜色及界面与代码字号。工作台导航与状态控件跟随宿主语言，捆绑工具正文保留原有语言。加载失败保留 frame 并提供重试；保存失败保留当前文档并显示未保存状态。桌面外壳等待持久保存确认后才停止 Host，保存失败则保留窗口。恢复的旧 CTF 标签转到工作台，不创建另一份 iframe。

文件与差异文本跟随独立代码字号，工具栏文字跟随界面字号。参见[主题设置](../ui-theme/README.zh.md#use-this-package)。

## 理解实现

桌面目录将完整工具包下载到用户应用数据目录，提供进度、取消和重试。部分下载和已校验介质会复用；安装后的工具可离线使用，重启和应用更新仍保留。首次访问目录会检查签名发布通道，也可点击“检查工具更新”。新增或更新工具需要用户明确下载；未变化的工具包继续使用本地版本。新增工具 ID 来自验证后的目录，无需在客户端写死条目。

<details>
<summary>实现细节</summary>

`shell.workspace` 贡献通过 `layout.region` 工厂各渲染一次现有导航、对话和辅助资源路由；隐藏面板只改变可见性，不替换其对话所有者。工作区声明 `rainy.ide.tools`，承载保留状态的工具工作台。Monaco、语言客户端及 xterm 从应用自身的离线 ESM 包加载，普通浏览器贡献保留共享 Client 模块格式。Host 拥有文件版本、工作区恢复修订、执行生命周期及语言服务器进程；浏览器校验响应并保留视图状态，没有独立运行时不变量。

<a id="model-experience"></a>
## 模型体验

### 浏览器品牌

#### 模型看到的内容

`slots` 注册仅渲染浏览器组件。“将选中代码发送到 AI”通过现有会记录日志的用户消息路径，明确提交选中源码、所属目录下的绝对路径及行范围。普通编辑及人工执行不会向对话注入文件内容。设置把模型、扩展和记忆变更委托给[桌面 Host](../../../apps/rainy-desktop/README.zh.md)。

#### Token 影响

本包不注册模型工具或自动提示词段落；明确发送的选中代码消息按普通用户消息计算 tokens。

#### KV Cache 影响

本包不改变供应商请求前缀，明确发送的选中代码消息遵循普通对话缓存行为。
